# <img src="public/icon.svg" width="36" align="center"> Calendar Puzzle

A daily puzzle game where you arrange 10 pieces on a calendar grid, leaving only today's month, day, and weekday uncovered. A new puzzle every day, with a unique solution for each date.

**[Play on keegant.dev →](https://calendar.keegant.dev)**

## How to play

- **Drag** pieces from the margins onto the board
- **Rotate** and **flip** pieces to find the right orientation
- To solve the puzzle, cover every cell except the three highlighted ones for today's date

## Controls

| Action                   | Method                   |
|--------------------------|--------------------------|
| Place a piece            | Drag onto the board      |
| Rotate clockwise         | `R` or the Rotate button |
| Rotate counter-clockwise | `Shift + R`              |
| Flip horizontally        | `F` or the Flip button   |
| Reset the board          | Reset button             |
| Hints (3 per puzzle)     | Lightbulb button         |
| Change puzzle            | Click the date picker    |
